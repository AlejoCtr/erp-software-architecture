# Proyecto ERP - Arquitectura de Software

Este repositorio contiene la documentación de arquitectura del Sistema ERP, desarrollada como parte del taller de ciclo de vida de desarrollo de software: desde la captura de requisitos ágiles hasta el diseño de arquitectura documentado con la plantilla arc42.

## Contenido

- **Backlog ágil:** gestionado en Jira (épicas, historias de usuario, criterios de aceptación y priorización MoSCoW).
- **Diagramas C4:** contexto (C1) y contenedores (C2), realizados con PlantUML.
- **Diseño detallado:** diagrama de secuencia y modelo entidad-relación (MER) para la historia "Registrar Producto".
- **Documentación de arquitectura:** estructurada con la plantilla arc42 (ver archivo `arc42-template-ES.md`).

## Estructura del repositorio

- `docs/images/` — diagramas exportados (C1, C2, secuencia, MER).
- `arc42-template-ES.md` — documento de arquitectura completo.
